## 1. 文章结束标签

```
<center><b>(本章完)</b></center>
```

## 2.regex 反向引用

notepad++ 正则反向引用 \n
vscode 正则反向引用 $n

## 3.替换 md 标题中索引

```
^(#+) \d

$1 n
\1 n
```

其中的 n 为具体的数字

## 4. 将连续多个换行符替换为1个换行符

```
(\r?\n){2,}
\r\n
```

## 5.巧妙利用正则表达式给中英文之间添加空格

```
([\u4e00-\u9fa5])([“]?[A-Za-z_-]+[”]?)([\u4e00-\u9fa5])
\1 \2 \3

([“]?[A-Za-z]+[”]?)([\u4e00-\u9fa5])
\1 \2
```

notepad++

```
([\x{4e00}-\x{9fa5}])(“?[_\.A-Za-z-]+”?)([\x{4e00}-\x{9fa5}])
\1 \2 \3

(“?[[_\.A-Za-z-]+”?)([\x{4e00}-\x{9fa5}])
\1 \2

([_\.A-Za-z -]+)([^_\.A-Za-z -])
\1 \2

([^_\.A-Za-z -])([_\.A-Za-z -]+)
\1 \2

([^_\.A-Za-z -])([_\.A-Za-z -]+)([^_\.A-Za-z -])
\1 \2 \3

([^"“”_\.A-Za-z -])(["“”_\.A-Za-z -]+)([[^"“”_\.A-Za-z -]])
\1 \2 \3

(“[-A-Za-z]+”)
 \1 
```
